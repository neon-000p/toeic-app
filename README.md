# TOEIC 学習アプリ

時事英語と実践対策（Part 3〜7）を1つにまとめる自作アプリ。GitHub Pages に置いて Android Chrome から使う。
ビルド不要・npm 不要。静的ファイルをそのまま置けば動く。

## 構成

```
news.html            時事英語モード（8ステップ）
core.js              共通コア（設定・語彙帳・学習ログ・読み上げ）
style.css            共通スタイル（色・部品）
data/news/index.json 目次（新しい順・最大30件）
data/news/*.json     1日分の教材
SCHEMA.md            教材データの仕様
SKILL-news-toeic-english.md  ルーティン側のスキル（ステップ5に JSON 出力を追加済み）
```

`core.js` と `style.css` は今後 `part3.html` などからも読む。同一オリジンなので
localStorage（設定・語彙帳・学習ログ）はページをまたいで自動的に共有される。
そのため ES モジュールにはしていない（`file://` で直接開けなくなるため）。

## 動かし方

**GitHub Pages**
リポジトリのルートにこのまま置いて Pages を有効にする。`news.html` が起動時に
`data/news/index.json` を読み、先頭の教材を開く。`?id=2026-09-12` で日付指定。

**ローカルで確認**
`file://` で直接開くと fetch がブロックされるため、内蔵サンプルが表示される
（画面は全部動く）。実データで確認したいときは簡易サーバーを立てる。

```bash
python -m http.server 4173
```

## データの入り方

1. 毎朝のルーティン（news-toeic-english スキル）が教材を生成
2. `data/news/YYYY-MM-DD.json` を書き出し、`index.json` の先頭に追加してコミット
3. アプリは次回起動時に自動で拾う

ルーティンからリポジトリへ push できない場合は、スキルが JSON をチャットに出力するので、
アプリの ⚙ →「教材を取り込む」に貼り付ける。取り込んだ教材は端末の localStorage に残る。

Part 3 以降は `data/part3/` など別ディレクトリ・別ルーティンで管理する。
片方のルーティンが失敗しても、もう片方に影響しない。

## 8ステップの流れ

読解 → 設問 → 解説 → 対訳 → 語彙 → 文法 → 背景 → 音読

- **読解**：英文のみ。語をタップすると語注が出る（`glossary`）。訳は出ない
- **設問**：2問に答えるまで「採点する」は押せない
- **解説・対訳**：採点するまでロック。先に訳を見て解いた気になるのを防ぐ
- **語彙**：★ で語彙帳に保存（復習画面は今後追加）
- **音読**：行タップで1文再生、通し再生、速度 0.6〜1.2
